# 传送门实验室 · Portal Lab

在线试玩：https://laziji724.github.io/portal-lab/

一个在浏览器里玩的第一人称 3D 物理解谜游戏。手持传送门枪，在白色面板上开出蓝、橙两扇门，人、方块和速度都能丝滑穿过，靠合理摆放传送门通过 7 章共 36 个关卡：非欧空间、放大缩小、激光光桥、弹射凝胶、反重力、圆形大厅、整片大陆和会重力翻转的小行星……自带关卡编辑器，支持电脑和手机。

## 快速开始

```bash
npm install
npm run dev      # 本地开发，浏览器打开终端里显示的地址
npm run build    # 打包到 dist/
npm run preview  # 预览打包结果
```

推送到 GitHub 的 `main` 分支后，`.github/workflows/pages.yml` 会自动构建并把结果推到 `gh-pages` 分支，GitHub Pages 从这个分支发布（Settings → Pages 的 Source 选 Deploy from a branch，分支 `gh-pages`）。

## 关卡（7 章 36 关）

- **第 1 章 · 基础训练**（7 关）：第一扇门、玻璃之隔、搬运方块、天降、飞跃、无限下落、隔栅取物。
- **第 2 章 · 非欧空间**（5 关）：空间门把远处的房间无缝接在一起。里面比外面大的小屋、按钮决定通往哪里的门、只能伸手和开枪的小窗、靠开关接成无限下落的洞、只能往前走的单向门。
- **第 3 章 · 放大与缩小**（5 关）：穿过大小不同的门，人和方块会跟着缩放。小个子压不动按钮，巨人钻不进普通门、却能跳过大坑、压得动重型按钮。
- **第 4 章 · 光与力**（5 关）：激光、折射方块、接收器、光桥、弹射板、弹跳 / 推进凝胶、往返平台，全都能穿过传送门。
- **第 5 章 · 综合难关**（5 关）：限时开关、消散力场、缩放、激光、光桥、弹射板组合在一起，最后一关「终极试炼」四个房间连环。

- **第 6 章 · 异形空间**（4 关）：不再是方盒子。圆厅、螺旋塔、一整片大陆（峡谷、巨石、酸湖）和傍晚天空下的浮空群岛，有的传送门开在斜坡和圆形墙上。
- **第 7 章 · 星球与重力**（5 关）：重力场可以朝任意方向，也可以指向球心。倒立之屋、重力翻转的滚筒隧道、能绕着走一圈的小行星、失重跳跃的双星、还有两颗星球之间的星门。穿过传送门时重力和视角会一起转过去。

每一关都有自动通关脚本（`tools/levels/chN.mjs`），证明它确实能解。

## 关卡编辑器

打开 `editor.html`（主菜单里也有入口）。可以添加墙体（白色 / 小号 / 大号面板、金属、混凝土、玻璃、栅格、两种凝胶）、方块、折射方块、按钮、重型按钮、开关、门、出口、酸液、灯、固定传送门、激光与接收器、光桥、弹射板、移动平台、消散力场、空间门、圆柱、球体（墙体可旋转、染色）、重力场（方块 / 球形）；拖动箭头移动，切到“缩放尺寸”改大小；右侧面板可精确输入数值。点 **▶ 试玩** 直接进游戏测试，**导出 JSON** 保存关卡。内置关卡定义在 `tools/levels/` 里，由 `tools/build-levels.mjs` 生成 JSON，格式与编辑器一致（说明见 `tools/levels/README.md`）。

## 技术要点

- **Three.js** 渲染，**Rapier**（WASM）做物理，Vite 打包，没有外部图片和音频：贴图用 Canvas 程序化生成，音效用 Web Audio 实时合成。
- **传送门渲染**：每扇门是一块“监控屏”，画面来自架在另一扇门后面、跟着玩家视角移动的虚拟相机（渲染到纹理）。用斜裁剪近平面剪掉出口门背后的墙；门中看门递归渲染，层数随画质调整。
- **穿越变换**：`T = M出口 · R(180°) · M入口⁻¹`，位置用 T，速度和朝向只用它的旋转部分，所以速度大小守恒、方向跟着门转。穿过地面门后歪掉的视角会平滑归正。
- **穿门碰撞**：门背后一段“隧道”里的墙体会对正在穿门的玩家和方块临时失效（Rapier 碰撞过滤钩子）；身体在门平面背后时，门洞边缘像一圈墙，不能横着从墙里走出去。
- **贴墙判定**：门必须完整落在一块白色面板上，超出边缘会自动往里推，和另一扇门重叠会自动推开，门洞里有障碍就失败。

## 画面与素材致谢

墙面、地面、金属板的质感来自 [ambientCG](https://ambientcg.com)（CC0 公共领域）的照片级 PBR 材质
（Plastic010/011/006、Terrazzo004、Tiles052、Concrete016、MetalPlates015A），
由 `tools/bake_textures.py` 加工成小体积的 webp 贴图放在 `public/tex/`（板缝、倒角、螺丝是脚本叠上去的）。
每一章有自己的配色主题（`src/world/theme.js`），画面带泛光后期、灯下光柱、飘浮尘埃，
踢脚线、灯带、天花横梁与管线由 `src/world/dressing.js` 根据关卡几何自动生成（只有外观，没有碰撞）。
手机和低配设备会自动关掉后期效果。
